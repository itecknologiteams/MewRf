🔌 API Endpoints

Endpoint 1: Tag Inquiry (Read-Only)

Purpose: Look up a tag and get consumer details

POST /payments/jazzcash/inquiry/ URL: http://221.120.248.114:8000/api/v1/payments/jazzcash/inquiry/

Request Body:

{ "tid": "E28011052000704A8F9F0AE3", "pp_SecureHash": "" }

Success Response (200):

{ "success": true, "message": "OK", "data": { "consumer_id": "62dbf8b8-e08a-487f-b4c9-ea886a5e930c", "vehicle_registration": "ABC-8123", "customer_name": "Kashif Mughal", "tid": "E28011052000704A8F9F0AE3", "current_balance": "1500.00", "status": "active" } }

Endpoint 2: Payment Notification (Idempotent)

Purpose: Credit balance after payment confirmation

POST /payments/jazzcash/payment/ URL: http://221.120.248.114:8000/api/v1/payments/jazzcash/payment/

Request Body:

{ "tid": "E28011052000704A8F9F0AE3", "amount": "500.00", "jazzcash_txn_id": "JC_KASHIF_001", "pp_SecureHash": "" }

Success Response (200):

{ "success": true, "message": "Balance updated", "data": { "jazzcash_txn_id": "JC_KASHIF_001", "new_balance": "2000.00", "topup_id": "36ac6d87-7940-4425-8726-ed849dc9c97b" } }
🔑 Key Feature - Idempotency: If you send the SAME jazzcash_txn_id twice, the first request credits the balance, and the second request returns already_processed=true with no additional credit. This is safe to retry on network failures!
