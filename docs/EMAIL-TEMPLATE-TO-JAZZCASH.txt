## API Summary

### Two Endpoints:

**1. Tag Inquiry (Read-Only)**
- POST `/payments/jazzcash/inquiry/`
- Input: TID + signature
- Output: Consumer details, balance, status

**2. Payment Notification (Idempotent)**
- POST `/payments/jazzcash/payment/`
- Input: TID, amount, jazzcash_txn_id, signature
- Output: New balance, topup transaction ID
- Duplicate txn_id returns 200 with `already_processed: true` (no double-credit)

**Both endpoints support:**
- Best-effort operation (no blocking)
- Consistent response envelope: `{ success, message, data/errors }`
- HTTP status codes: 200, 400, 401, 404, 500
